# Codex brief — runtime 0.43.2 (2026-09-29)

Tracks Cachalot runtime **0.43.2** (HANDOFF section 18.23 item 8). No knob or endpoint changed. One new log line and
one behaviour change a chat view may notice:

- A MiniMax/GLM reply that stops (loop guard or length limit) inside a tool call that never closed no longer
  returns the raw call markup as `content`: the reply is the text before the call, `finish_reason` stays `stop` or
  `length`, and the server logs `[tool call] unclosed block dropped (N chars) at a loop guard stop` (or `length`).
  If the Cockpit parses `[loop guard]` lines, parse this one beside it and show both as a "reply cut" marker.
- The startup line prints the real version again (`cachalot 0.43.2`); 0.42.0-0.43.0 printed 0.41.0. If Studio
  reads the runtime version from that line for `compat.yaml` checks, those three releases reported low.
