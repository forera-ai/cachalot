# Studio brief: runtime 0.60.0 (HANDOFF section 18.66)

Contract-file diffs first:

- `serve.sh` now exports `CACHALOT_DECODE_MISS_BUDGET=0` by default (a changed default). `CACHALOT_DECODE_MISS_BUDGET=off` or `exact` restores the exact decode path; the startup line `decode miss budget 0: ...` appears by default now. `/v1/stats` `decode_miss_budget` is 0 (not null) and `skipped_experts` counts dropped experts, both already existing fields.
- New environment knobs on `cachalot.cli serve` (DeepSeek): `CACHALOT_SYSTEM_DATE_REUSE` (default on, `0` off) and `CACHALOT_SYSTEM_DATE_REUSE_DAYS` (default 7). New startup line `system date reuse: an agent's date line shows a date up to 7 days old ...`; a new request log line `[request] system date: showing <old date> for <true date>`. New file `system-dates.json` beside the prefix snapshots.
- 0.59.0 (already shipped): pin files `prefix-<n>-<hash>.safetensors` of <= 8,192 tokens in the snapshot directory; the startup line `prefix snapshots: ... more on disk` counts them.

UI changes: show "decode drops misses (faster, lowers quality slightly)" as the default state of the DeepSeek server with an off switch to the exact path; show "system date reuse" as an on-by-default option whose cost is that the model sees a date up to 7 days old.
