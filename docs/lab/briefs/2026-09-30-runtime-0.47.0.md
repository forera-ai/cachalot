# Codex brief — runtime 0.47.0 (2026-09-30)

Tracks Cachalot runtime **0.47.0** (HANDOFF section 18.31). One default changed in a launch script; no knob, endpoint,
stats field or log-line format changed.

- **Default:** `serve-minimax.sh` now passes `--default-temperature 0.7` (was 1.0). The startup line reads
  `a request without them samples at temperature 0.7, top_p 0.95`. A request's own `temperature` always wins.
- **Studio:** if the launch panel shows or sets MiniMax's default temperature, its default is 0.7 now; a field that
  appends `--default-temperature X` after the script name overrides it (the last flag wins). If Studio sends its own
  `temperature` in chat requests, consider 0.7 for MiniMax to match (HANDOFF 18.29: 1.0 derailed long tool results
  5 times in 12, 0.7 once). The terminal chat (`chat-minimax.sh`) still uses 1.0; GLM stays 0.6.
