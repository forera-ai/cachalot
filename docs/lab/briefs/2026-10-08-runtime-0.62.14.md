# Lab brief: runtime 0.62.14 (HANDOFF section 18.106)

Contract-file diffs first:

- **`/v1/stats` (GLM server only): new field `skipped_experts`** (integer, experts a decode miss budget dropped since start; always 0 while the budget is off). DeepSeek's `/v1/stats` already had it; MiniMax's server shares the GLM engine and reports 0.
- **New knob:** `CACHALOT_GLM_DECODE_MISS_BUDGET` (unset, `off` or `exact` is off; an integer is the per-layer cap on non-resident experts read in decode). When set, the GLM server prints `GLM decode miss budget N: ...` at startup. It changes outputs.
- **Default changed:** `serve-glm.sh` now exports `CACHALOT_GLM_PREDICT_TOPK=0` (decode prefetch off; outputs unchanged). Predicted-load counters (`predicted_loads`, `predicted_used`) therefore read 0 on a default GLM server.

UI changes: optional. Show `skipped_experts` next to the hit rate when it is nonzero, and mark a run with a budget as output-changing.
