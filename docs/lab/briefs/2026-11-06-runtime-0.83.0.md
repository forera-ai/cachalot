# Lab brief: runtime 0.83.0, GLM in-block snapshot pins (HANDOFF section 18.273)

Contract-file diffs first. **One new knob, on by default:** `CACHALOT_GLM_BLOCK_PINS` (default 3, `0` off). The last chunk boundaries inside a GLM system block go to disk. MiniMax keeps none. Outputs are bit-identical.

- **Startup line:** `prefix snapshots: ... N more on disk` now also counts pins, which are indexed and not preloaded.
- **`[request]` line:** form unchanged; `reused=` can now be a chunk boundary such as 14336.
- New files in `prefix-snapshots-glm/`, about 0.3 GiB each, at most 8; `index.json` marks them `"pin": true`.
- No `/v1/stats` field or endpoint changed.
