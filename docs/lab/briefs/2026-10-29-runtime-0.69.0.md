# Lab brief: runtime 0.69.0, `cachalot.auxiliary` and `cachalot aux` (Apple's on-device model as an auxiliary engine, default off; HANDOFF section 18.229)

Contract-file diffs first. **New environment knobs, all off or inert by default, read only by `cachalot.auxiliary`** (no server, engine, `serve*.sh` or `chat*.sh` reads them): `CACHALOT_AUX_ENABLED`, `CACHALOT_AUX_PROVIDER` (`apple_foundation_models` | `deterministic`), `CACHALOT_AUX_MODEL` (only `system`), `CACHALOT_AUX_ISOLATION` (`process` | `inline`), `CACHALOT_AUX_TIMEOUT_MS`, `CACHALOT_AUX_MAX_CONCURRENT_REQUESTS`, `CACHALOT_AUX_QUEUE_LIMIT`, `CACHALOT_AUX_USE_CASE`, feature flags `CACHALOT_AUX_CLASSIFICATION`, `_STRUCTURED_EXTRACTION`, `_CONTEXT_COMPRESSION`, `_SEMANTIC_VALIDATION`, `_ADAPTIVE_ROUTING`, and `CACHALOT_AUX_COMPRESSION_MIN_TOKENS` / `_MAX_RATIO` / `_MAX_UNGROUNDED`. **One new CLI command**: `cachalot aux check|respond|classify|extract|compress` (prints JSON or text; never loads a target model). **No** new endpoint, `/v1/stats` field, `[request]` log field, startup phase or model family; the serving path is unchanged.

New benchmark output: `benchmarks/apple_fm_bench.py` writes a manifest (`run_manifest.py` format) and JSON-lines rows to `benchmarks/results/apple-fm/<arm>-<utc>.jsonl` with fields `experiment_id`, `manifest_id`, `hardware`, `macos_version`, `provider`, `provider_version`, `target_model` ("none" for every arm so far), per-arm measurement fields (`auxiliary_latency`, `time_to_first_token`, `tokens_per_second`, `prompt_tokens`, `ratio`, `fact_retention`, `median_rate` with `rate_unit`, ...) and a final `measure: "summary"` row.

UI notes for Lab: if Lab lists runtime knobs, group these under "auxiliary (Apple on-device model)", off by default, with the note "not in the serving path; compression measured as a loss, routing not validated for use". `cachalot aux check` is the availability probe (`available`, `unavailable_reason`, `context_tokens`, `local_only` always true). A Lab view comparing auxiliary rows should keep auxiliary throughput, target throughput and combined throughput as separate series; the contention rows pair a GPU rate (B/s or FLOP/s) with the system model's tok/s per cell (gpu, fm, both).
