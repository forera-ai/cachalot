# Lab brief: runtime 0.79.0, a default-off vision upscale (HANDOFF section 18.264)

Contract-file diffs first. **One new knob, off by default:** `CACHALOT_VISION_MIN_PIXELS=N` (unset, empty, 0, or at most 544 x 544 =
off). With it on, a DeepSeek image under N pixels is upscaled before the vision tower, so it takes more image tokens (a 492 x 512
screenshot: 486 instead of 198 at N = 810,000), capped at 1,024 as before.

- **Startup line (new, only when on):** `vision upscale: images under <N> pixels are upscaled before the tower (checkpoint: 544 x 544; ...)`.
- **`[request]` line:** unchanged in form; `prompt=` grows by the extra image tokens for small images.
- **Prefix cache:** an image's span key includes N when it is not the checkpoint's; snapshot files and the shipped setting are unchanged.
- No `/v1/stats` field, endpoint or launcher default changed. 0.78.x briefs: none (measurements only, plus 0.78.0's rare-skip brief).

UI notes for Lab: a per-request image-token count (prompt growth on image turns) would show the knob's cost; Hermes's `vision_analyze`
tool calls on image turns are the behaviour it changes.
