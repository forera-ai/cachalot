# Lab brief: runtime 0.60.4 (HANDOFF section 18.70) — the app is now Cachalot Lab

The owner renamed the desktop app on 2026-10-05: **Cachalot Studio is now Cachalot Lab.** No runtime knob, flag, default, `/v1/stats` field, log line, startup phase, endpoint or model family changed in this release; this brief is about the name and about where the runtime keeps your briefs.

Contract and path changes on the runtime side:

- The briefs directory moved from `docs/studio/` to `docs/lab/` in the runtime repository. The product brief is now `docs/lab/CODEX-LAB-PROMPT.md` (was `docs/studio/CODEX-STUDIO-PROMPT.md`); per-release briefs are `docs/lab/briefs/YYYY-MM-DD-runtime-X.Y.Z.md`. Older briefs moved with the directory and kept their file names; their text still says "Studio" because it records what was sent at the time.
- The runtime's README section is now "Cachalot Lab". From this release on, every runtime brief is titled "Lab brief" and refers to the app as Cachalot Lab.
- The runtime repository also uses "the lab" in lower case for its research direction (`docs/RESEARCH-DIRECTION.md`: per-token anatomy, run manifest, scorecard, sweeps as curves, energy). Cachalot Lab is the app that will eventually display that research's scorecards and curves; the runtime will send a brief when it has a stable schema to show (the charter's section 9, question 3, is still open).

What the rename asks of you (yours to own, not the runtime's):

1. Rename the product everywhere a user or a developer sees it: app name, window titles, menus, About box, bundle display name, docs, README, HANDOFF, in-app copy.
2. Decide and carry out the identifier migration: the Git remote (`https://github.com/prooshani/cachalot-studio.git`), the working directory (`/Volumes/X10Pro/Cachalot Studio`), the bundle identifier, the `Application Support/Cachalot Studio` data directory and the `cachalot-studio/...` keychain service names. Move existing user data, profiles and keychain items so nothing is lost on first launch after the rename, and keep the in-app updater working across it.
3. Update every reference to the runtime's `docs/studio/` path in your repository (your HANDOFF, your `runtime-contract/` notes, scripts) to `docs/lab/`.
4. Report the new remote URL, working directory and bundle identifier to the owner, so the runtime's docs, its project map and its code-graph project name (`Volumes-X10Pro-Cachalot-Studio` today) can follow.

UI changes: none beyond the name.
