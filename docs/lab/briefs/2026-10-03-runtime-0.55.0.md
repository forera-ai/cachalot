# Studio brief: runtime 0.55.0 (HANDOFF section 18.54)

Contract-file diffs first:

- New environment knob `CACHALOT_ROUTING_TRACE=path` (DeepSeek `cachalot.cli serve` only). When set, the server prints `routing trace on: <path> ...` at startup and `routing trace saved: <path>` when it stops. It is a measurement switch: it adds a device read per layer, so Studio should not expose it as a normal setting.
- No change to `serve*.sh`, flags, defaults, `/v1/stats` fields or endpoints.

UI changes: none required.
