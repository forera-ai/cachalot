# Lab brief: runtime 0.74.0, DI-2 bounded decoder replay behind `CACHALOT_PREFILL_DECODER_KEEP` (default off; HANDOFF section 18.251)

Contract-file diffs first. **One new knob, default off:** `CACHALOT_PREFILL_DECODER_KEEP=N` (integer, 128 to 2,541). It acts only inside a DI-1
encoder-only prefill (`CACHALOT_PREFILL_ENCODER_ONLY=1`, the `serve.sh` default): the decoder half replays the last N rows instead of the exact
2,541, with every decoder window cut at the replay start. An out-of-range value refuses to start (`ValueError`). **One new startup line** when it is
set, after the DI-1 line: `DI-2 bounded replay on: the decoder half replays only the last N rows with windows cut at the replay start (approximate;
snapshots keyed on it; unset CACHALOT_PREFILL_DECODER_KEEP is the exact tail)`. **Snapshot key:** with the knob set the identity version is
`0.68.0-di1.1-keepN`, so its snapshots never mix with the exact tail's. No default, `/v1/stats` field, `[request]` field or endpoint changed.

Measured (1017, the long `pareto.py` gate): KL against the full prefill 0.0011 / 0.0012 / 0.0017 / 0.0020 at keep 1,024 / 512 / 256 / 140, noise arm
0.0116; all inside noise. Speed through the server not measured yet.
