# Lab brief: runtime 0.72.1, DeepSeek-V4.1-Flash-1017 runs on Cachalot (HANDOFF section 18.243)

This brief also covers 0.71.2's launch-script change (HANDOFF section 18.240), which had no brief of its own.

Contract-file diffs first. **No knob, flag, `/v1/stats` field, `[request]` field, startup line or endpoint changed in 0.72.1.**
**One launch contract from 0.71.2 is now in use:**

- `serve.sh` and `chat.sh` take `CACHALOT_MODEL_PATH` from the environment. The default is still `/Volumes/X10Pro/Flash4-1/DeepSeek-V4.1-Flash`.
- They derive the expert bank from the checkpoint directory's name:
  - `$HOME/<name>-q2g128` when that directory has a `.cachalot-verified` marker;
  - otherwise `<name>-q2g128` beside the checkpoint.
- They derive the hotlist from the same name:
  - `~/cachalot-hotlist.json` for `DeepSeek-V4.1-Flash`;
  - `~/cachalot-hotlist-<name>.json` for any other revision, when that file exists;
  - otherwise none. `CACHALOT_HOTLIST=` (empty) disables the hotlist.
- The model id served stays `deepseek-v4.1-flash` for both checkpoints. The checkpoint is visible only in the startup lines:
  - `cachalot 0.72.1: loading <path>`
  - `expert bank: <path> ...`

UI notes for Lab:
- **Which checkpoint is running.** Show it per server: the basename of the `loading` path and of the `expert bank` path. The model id cannot tell the two checkpoints apart.
- **Budget 0 and tool calls.** Under the decode miss budget, show "drops non-resident experts: about 21 % faster decode; can garble integer tool arguments (Hermes repairs them with a retry)".
- **Wired governor log lines.** Lines `wired fit: expert slots A -> B (system wired X GiB, ceiling 73.0)` came 20 to 23 times in a 30-minute Hermes session with Hermes Desktop open. A run of shrinks shows another app holding wired memory. Plotting slots against system wired memory would show it.
- **Failed requests.** A failed request is not logged by the server. The client gets the exception text (seen: `'w1.weight'`), and the server prints no `[request]` line for it. Until the runtime logs tracebacks, Lab can only detect it as a request with no `[request]` line.
