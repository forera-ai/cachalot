# Codex brief — runtime 0.51.0 (2026-09-30)

Tracks Cachalot runtime **0.51.0** (HANDOFF sections 18.39-18.40). GLM gains image input; nothing else changed.

- **Endpoint behaviour:** `./serve-glm.sh` (model id `glm-5.3-flash`) accepts OpenAI `image_url` content parts (a `data:` URI, an
  http(s) URL or a local path) in `/v1/chat/completions`. The vision tower loads on the first image; a first image request pays a
  cold prefill of its tokens (a 640x360 image is ~300 tokens, up to 8,000 for a large one at roughly 90 tok/s).
- **Stats:** `/v1/stats` for GLM now carries `images_served`; the `[request]` line shows `images=N`.
- **Studio:** enable image attachment for GLM as for DeepSeek. Videos are not supported. MiniMax has no vision.
