# Codex brief — runtime 0.42.0 (2026-09-29)

Tracks Cachalot runtime **0.42.0** (HANDOFF section 18.23). One new MiniMax knob, opt-in and **not bit-identical**
(off by default, Hamed's call, like `CACHALOT_MINIMAX_MISS_DROP`); no endpoint, stats field or log line changed.
With it on, MiniMax's disk snapshots carry a different numerics tag (`-pfdrop0.2-sub4`), so they are written and read
apart from the exact path's: switching it on the first time re-prefills Hermes's system block once.

## 1. Contract-file edits

### `runtime-contract/knobs.yaml`

```yaml
- key: CACHALOT_MINIMAX_PREFILL_MISS_DROP
  kind: env
  families: [minimax-m3]
  type: float
  default: {minimax-m3: 0}
  range: [0, 0.25]
  group: speed
  effect: changes-outputs
  restart_required: true
  stability: opt-in
  since: 0.42.0
  summary: >-
    In a prefill chunk, a missing expert is not read when every token routed to it gives it under this share of
    its routing weight and has a resident runner-up among the next CACHALOT_MINIMAX_MISS_SUB ranks (4 when unset);
    those tokens use the runner-up. 0.20: short follow-up prefills (200 tokens) -11 to -12 %, paired NLL within
    +0.002 to +0.006 of exact (a rounding change: +0.002). 0 is exact.
  doc: HANDOFF 18.23
- key: CACHALOT_MINIMAX_PREFILL_SUB_MAX_ROWS
  kind: env
  families: [minimax-m3]
  type: int
  default: {minimax-m3: 32}
  group: speed
  effect: changes-outputs
  restart_required: true
  stability: opt-in
  since: 0.42.0
  summary: Experts routed to more tokens than this are always read (only matters with the knob above on).
  doc: HANDOFF 18.23
```

### `runtime-contract/compat.yaml`

- `minimax_prefill_miss_drop: ">=0.42.0"`.

## 2. UI changes

- **Profiles → Speed (MiniMax), the block that holds "Miss substitution":** a second toggle "Prefill miss
  substitution" writing `CACHALOT_MINIMAX_PREFILL_MISS_DROP=0.20` (off writes nothing). Same warning label as the
  decode switch: "changes outputs slightly; quality measured inside or near rounding noise". It is independent of the
  decode switch; the two share `CACHALOT_MINIMAX_MISS_SUB`.
- **Cockpit:** nothing new to parse.
