# Lab brief: runtime 0.62.0 (HANDOFF section 18.92)

Contract-file diffs first:

- No `/v1/stats` field, endpoint or default changed.
- **Knob extended:** `CACHALOT_ROUTING_TRACE=<file>` (until now DeepSeek only) is read by the GLM and MiniMax servers too. At startup the server prints `routing trace on: <file> (<n> streaming MoE layers; saved at exit; no router weights)` and, at exit, `routing trace saved: <file>`. For MiniMax with miss substitution on it also prints a line starting `routing trace WARNING`.
- The trace file is the existing `.npz` format (`phase`, `layer`, `position`, `experts`, `segments`; no `weights`, no `pred_*`). Positions are a per-(phase, layer) counter, unique within a run, not restarting per request.

UI changes: optional. A run's configuration can show whether a routing trace was on; a trace of a speed run is not a speed baseline (it is off by default and costs ~2.3 us a layer-token).
