# Lab brief: runtime 0.76.0, exact decode inside tool-call blocks behind `CACHALOT_DECODE_TOOL_EXACT` (default off; HANDOFF section 18.255)

Contract-file diffs first. **One new knob, default off:** `CACHALOT_DECODE_TOOL_EXACT=1` (DeepSeek `serve` only). It acts only when a decode miss
budget is set (`CACHALOT_DECODE_MISS_BUDGET`, `serve.sh` sets 0): once a reply's text contains the DSML tool-call opener, the budget is lifted for
the rest of that reply and restored when the request ends. **One new startup line** when it is set, after the miss-budget line: `tool-call blocks
decode exact: the miss budget is lifted from a reply's tool-call opener to its end (CACHALOT_DECODE_TOOL_EXACT)`. No default, `/v1/stats` field,
`[request]` field, snapshot key or endpoint changed; prefill is untouched.

Measured (1017, replay of Hermes's Desktop-listing turn, 24 replies an arm): non-JSON `search_files` `limit` 2 of 24 at budget 0, 0 of 24 with the
knob; tool-call decode cost about 0 with the experts resident, about 15-30 % with 10-27 missing a token.

UI notes for Lab: if Lab shows decode settings, read the knob from its startup line (present = on) and show it under the miss budget as "default
off, changes outputs only inside tool-call blocks".
