changed.

- **Knobs (GLM):** `CACHALOT_GLM_PREDICT_TOPK` (default 5; 0 turns the next-layer prefetch off), `CACHALOT_GLM_PREDICT_LIMIT`
  (reads per layer, 0 = all), `CACHALOT_GLM_PREDICT_AFTER_DEMAND` (default 1). Same tokens either way.
- **Studio:** if the launch panel lists GLM's advanced knobs, add these three. `/v1/stats` is unchanged; its predicted-load
  counters (`predicted_loads`, `predicted_used`) now move for GLM decode.
