# Lab brief: runtime 0.71.0, `CACHALOT_ATTN_ACT_QUANT_O` (the reference's FP8 round trip of the attention output, default off; HANDOFF section 18.238)

Contract-file diffs first. **One new environment knob, off by default:** `CACHALOT_ATTN_ACT_QUANT_O` (`1` enables; read once at import by `cachalot.model.fp8_fused_metal`). With it on, DeepSeek's attention output is quantised to FP8 and back (32-value blocks, power-of-two scales, E4M3; the reference's `act_quant`) before the grouped `wo_a` projection, in decode, prefill and the DSpark draft. It changes outputs; with it off the runtime is bit-identical to 0.70.1. No `serve*.sh` or `chat*.sh` sets it, no `/v1/stats` field, log line, startup phase or endpoint changed, and no default changed. Snapshot numerics tags are unchanged (prefill KV saved with the knob on is not marked).

Measured (DeepSeek, `pareto.py`, 576 teacher-forced positions and 21 tasks): dNLL +0.0047 nats [-0.0156, +0.0261], KL mean 0.0171 against a re-chunking's 0.0140, tasks 20 of 21 like the reference, decode step 142 against 140 ms (one process each).

Also new in this release, instruments only: `benchmarks/pareto.py` long-context mode (arm `encoder_only`, base `prefill_chunk`, `battery: false`) and `benchmarks/di1_tail_equality.py --text-file/--text-start`. The DI-1 knob `CACHALOT_PREFILL_ENCODER_ONLY` (0.67.0) is unchanged and still off; its measured numbers (22k cold prefill -39 %, long-gate KL 0.0014) are in `docs/V270-MAC-JOBS-RESULTS.md`.

UI notes for Lab: if Lab lists runtime knobs, show `CACHALOT_ATTN_ACT_QUANT_O` under DeepSeek numerics as "reference parity, output-changing, off; quality-neutral on the gate", next to `CACHALOT_PREFILL_ENCODER_ONLY` ("prefill speed, output-changing within noise, off").
