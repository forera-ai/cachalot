# Lab brief: runtime 0.81.0, GLM vision upscale knob (HANDOFF section 18.270)

Contract-file diffs first. **One new knob, off by default:** `CACHALOT_GLM_VISION_MIN_PIXELS=N`. Unset, empty or `0` is the checkpoint's preprocessing. When set, GLM still images under N pixels are upscaled before the vision
tower and take more image tokens. It is separate from DeepSeek's `CACHALOT_VISION_MIN_PIXELS`. `serve-glm.sh` documents it and does not set it.

- **Startup line (only when set):** `GLM vision upscale: still images under 810,000 pixels are upscaled before the tower ...`.
- **`[request]` line:** form unchanged; `prompt=` is larger on turns with small images (a 492 x 512 screenshot: +714 tokens).
- No `/v1/stats` field, endpoint or snapshot key changed. Video is untouched.

UI notes for Lab: if Lab shows active knobs from startup lines, treat this as an output-changing GLM setting. No change is needed otherwise.
