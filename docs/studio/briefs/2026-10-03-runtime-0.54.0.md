# Studio brief: runtime 0.54.0 (HANDOFF section 18.53)

Contract-file diffs first:

- New environment knobs (DeepSeek runtime, on by default): `CACHALOT_WIRED_CEILING_GIB` (default 76 % of RAM, 73.0 GiB on 96 GiB; `0` turns the governor off), `CACHALOT_WIRED_HYSTERESIS_GIB` (1.5), `CACHALOT_WIRED_GROW_QUIET_S` (60), `CACHALOT_WIRED_CHECK_EVERY` (16 decode tokens).
- New server log line: `wired fit: expert slots A -> B (system wired X GiB, ceiling Y)`, printed whenever the DeepSeek expert capacity changes. The server's `expert budget` startup line is now an upper bound, not a promise.
- No new `/v1/stats` fields and no new endpoints. `/v1/stats` `resident_experts` can now shrink and grow during a session.

UI changes: none required. If Studio shows the DeepSeek expert cache size, read it from `/v1/stats` rather than the startup line.
