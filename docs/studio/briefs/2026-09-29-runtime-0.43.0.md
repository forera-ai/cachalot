# Codex brief — runtime 0.43.0 (2026-09-29)

Tracks Cachalot runtime **0.43.0** (HANDOFF section 18.23 item 7). Defaults only; no endpoint, stats field or log line
changed.

## 1. Contract-file edits

### `runtime-contract/knobs.yaml`

- `CACHALOT_MINIMAX_MISS_DROP`: `default: {minimax-m3: 0.20}`, `stability: shipped`, `since` unchanged; summary gains
  "on by default since 0.43.0; 0 is the exact path".
- `CACHALOT_MINIMAX_MISS_SUB`: `default: {minimax-m3: 4}`.
- `CACHALOT_MINIMAX_PREFILL_MISS_DROP`: `default: {minimax-m3: 0.20}`, `stability: shipped`; same summary addition.

### `runtime-contract/compat.yaml`

- `minimax_miss_substitution_default_on: ">=0.43.0"`.

## 2. UI changes

- **Profiles → Speed (MiniMax):** both "Miss substitution" toggles now show **on** for runtime >= 0.43.0. Turning
  one off writes `0` for its drop knob (not an empty value, which now means on). An "Exact outputs" preset writes
  `CACHALOT_MINIMAX_MISS_DROP=0 CACHALOT_MINIMAX_PREFILL_MISS_DROP=0`.
- **First launch after the upgrade:** expect one long first request (the saved system block is keyed to the exact
  path's numerics and is prefilled again once, ~100-130 s for Hermes's block). If the cockpit shows a "cold start"
  hint, show it for this case too.
