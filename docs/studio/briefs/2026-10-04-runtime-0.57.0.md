# Studio brief: runtime 0.57.0 (HANDOFF section 18.59)

Contract-file diffs first:

- New environment knob `CACHALOT_DECODE_MISS_BUDGET=N` (DeepSeek `cachalot.cli serve`; unset, empty or negative = off, the default; `serve.sh` does not set it). When set, the startup log gains one line: `decode miss budget N: at most N non-resident experts are read per layer in decode, the rest dropped (changes outputs; CACHALOT_DECODE_MISS_BUDGET)`.
- No new `/v1/stats` field: `decode_miss_budget` (null when off) and `skipped_experts` (a running count of dropped experts) already exist in `/v1/stats`.
- No change to `serve*.sh`, flags or endpoints.

UI changes: none required. If Studio exposes it, it is an advanced, output-changing speed option that is off by default (measured -22.6 % a token at a 22k context with budget 0); label it as lowering quality, not as a free speed-up. Quality at agent scale is not yet measured.
