# Codex brief — runtime 0.44.0 (2026-09-29)

Tracks Cachalot runtime **0.44.0** (HANDOFF section 18.24). Two new environment knobs, one behaviour change the
Cockpit may surface, no endpoint or log-line format changed.

- **New knobs (MiniMax server and chat):** `CACHALOT_HOST_GROW_QUIET_S` (default 60; seconds without macOS memory
  pressure before the expert cache may grow; 0 turns the pressure watcher off and restores 0.43's governor) and
  `CACHALOT_HOST_SHRINK_EVERY_S` (default 10; at most one slab given back per interval for pressure). Both belong
  with the memory knobs in Studio's launch panel, advanced section, defaults shown.
- **Behaviour:** under memory pressure the existing `memory fit: expert slots A -> B (...)` lines now also appear in
  the middle of a reply (a slab given back at a decode token), and the cache stays smaller for about a minute after
  pressure. A Cockpit memory graph that plots capacity from these lines needs no change; one that assumed fits only
  at a request's start and every 512 tokens should accept them at any token.
- **Restart:** the first request after a restart reuses the saved system block again (`prefix snapshots: 1 loaded`
  at startup). Snapshot files now carry the runtime identity in their name, so the snapshot directory may hold two
  files for the same block (one per configuration, e.g. exact and substitution on); the older ones age out.
